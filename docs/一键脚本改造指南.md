# 一键脚本改造指南（方案2：品牌资源独立仓库）

> 目标：在你现有的 KTG-MES 一键部署脚本里，加入"自动拉取品牌资源 + 应用定制"的步骤
> 原则：原版源码不变，品牌资源独立仓库，脚本自动拼接

---

## 一、改造思路

```
原脚本流程：
  安装依赖 → clone 原版源码 → 建库 → 改配置 → 编译 → 启动 → 体检

改造后流程：
  安装依赖 → clone 原版源码 → clone 品牌资源 → 应用品牌定制 → 建库 → 改配置 → 编译 → 启动 → 体检
                                          ↑ 新增这一步
```

---

## 二、需要修改的位置

打开你的 `ktg-mes-v1.0.sh`，找到以下 3 个位置插入代码：

### 位置1：全局配置区（文件开头）

在文件顶部的"全局配置"部分，新增品牌仓库地址配置：

```bash
# ======================= 品牌定制配置（新增） =======================
# 品牌资源仓库地址（你自己的 GitHub 仓库）
BRAND_REPO="${KTG_BRAND_REPO:-https://github.com/你的账号/ktg-mes-brand.git}"
# 品牌仓库分支
BRAND_BRANCH="${KTG_BRAND_BRANCH:-main}"
# 品牌资源本地目录
BRAND_DIR="$WORK_DIR/ktg-mes-brand"
# 是否启用品牌定制（设为0可关闭）
ENABLE_BRAND="${KTG_ENABLE_BRAND:-1}"
```

---

### 位置2：clone 源码之后

找到脚本里 `git clone` 前端源码的那段（大约在 `FRONTEND_DIR` 相关的地方），在 clone 完前端之后，加入 clone 品牌仓库的代码：

```bash
# ======================= 新增：Clone 品牌资源 =======================
if [ "$ENABLE_BRAND" = "1" ]; then
    step "克隆品牌定制资源"

    if [ -d "$BRAND_DIR" ]; then
        info "品牌目录已存在，拉取最新版本..."
        git -C "$BRAND_DIR" pull origin "$BRAND_BRANCH"
    else
        info "克隆品牌资源仓库：$BRAND_REPO"
        # 支持 GitHub 加速
        git clone --depth 1 -b "$BRAND_BRANCH" \
            "$GH_PROXY/$BRAND_REPO" "$BRAND_DIR"
    fi

    # 确保脚本可执行
    chmod +x "$BRAND_DIR/scripts/apply-brand.sh"

    ok "品牌资源准备完成"
fi
```

---

### 位置3：前端构建之前

找到脚本里前端构建（`build-fe` 或 `npm run build:prod`）之前，加入应用品牌的步骤：

```bash
# ======================= 新增：应用品牌定制 =======================
if [ "$ENABLE_BRAND" = "1" ] && [ -f "$BRAND_DIR/scripts/apply-brand.sh" ]; then
    step "应用 KTG-MES 品牌定制"

    info "开始应用品牌资源到前端项目..."
    bash "$BRAND_DIR/scripts/apply-brand.sh" "$FRONTEND_DIR"

    ok "品牌定制应用完成"
fi
```

## 四、新增命令支持（可选）

在脚本的命令分发部分，新增单独应用品牌的命令，方便用户单独执行：

```bash
# 在 case 命令分发里加一个分支
apply-brand)
    require_root
    bash "$BRAND_DIR/scripts/apply-brand.sh" "$FRONTEND_DIR"
    ;;
```

用法：

```bash
sudo ./ktg-mes.sh apply-brand
```

## 五、环境变量覆盖（高级）

用户可以通过环境变量自定义品牌配置，无需改脚本：

```bash
# 例：使用测试分支的品牌资源
sudo KTG_BRAND_BRANCH=dev ./ktg-mes.sh install

# 例：关闭品牌定制，用原版
sudo KTG_ENABLE_BRAND=0 ./ktg-mes.sh install

# 例：使用另一个品牌仓库
sudo KTG_BRAND_REPO=https://github.com/xxx/ktg-mes-brand-v2.git ./ktg-mes.sh install
```

## 八、常见问题

### Q: 品牌仓库 clone 失败怎么办？
A: 脚本已内置 GitHub 加速（`$GH_PROXY`），如果还失败，检查网络或手动设置 `KTG_GH_PROXY` 环境变量。

### Q: 重复执行脚本会怎样？
A: apply-brand.sh 每次都会自动备份，重复执行安全，不会报错。

### Q: 原版代码更新后定制会丢吗？
A: 会。因为重新 clone 会覆盖前端目录。解决方法：重新跑一遍 `apply-brand.sh` 即可恢复定制。

### Q: 怎么临时关闭品牌定制？
A: 加环境变量：`sudo KTG_ENABLE_BRAND=0 ./ktg-mes.sh install`
